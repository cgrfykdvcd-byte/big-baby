# 巨婴系统 · 校园行动管理器

按《巨婴系统_下一期迭代方向_V1.0》实现：信息进入 → 事件合并与理解 → 角色行动项 → 用户确认 → 日程执行。

## 本期交付

- 自有账号注册、登录、退出、密码修改；支持为原 ChatGPT 空间绑定账号，保留原数据。
- D1 用户隔离与跨设备持久化；密码使用随机盐 PBKDF2-SHA256，7 天 HttpOnly Secure 会话、服务端撤销及登录速率限制。
- 一批最多 500 条 / 20 万字符，聊天时间头识别、按原始顺序保留原文、相关事件合并、重复导入幂等。
- 事件摘要标题、角色子任务/须知、独立截止节点、提交对象/方式、原文证据、手动修订历史。
- 相关新通知提示旧截止 → 新截止，保留两份原文，不静默替换已确认任务。
- 文件中心：15 MB 上限，文字 PDF（150 页）、DOCX、XLSX、文本、CSV；PNG/JPEG/WebP 通过已配置的视觉模型识别（10 MB）。图片 OCR 先核对文字，再分析。
- 课表表格或 AI 导入；编辑预览再保存；周视图/列表；课程、个人安排及各子任务截止同屏；重复课程每次独立完成记录；时段冲突提示。
- 待办/子任务可转为日程草稿，由用户选择执行时段，不将截止时间当作执行时间。
- 可替换 Chat Completions 兼容 AI 接口，文字/视觉模型分工。服务端 AES-GCM 加密保存用户 API Key，结构与证据校验、规则回退及最近分析记录。
- P2 授权采集接口 PoC：个人来源令牌、通用 JSON 接收、批次幂等、最近接收时间与撤销能力。

## 仍需配置与范围边界

- AI 需用户在“AI 设置”填写地址、模型 ID、API Key 并启用；无密钥时可使用规则提取。
- 企业微信一侧未连接。`/api/inbound/:sourceId` 是通用采集器 API，不是可直接填写到企业微信后台的加密回调。实际群消息接入需管理员授权和对应适配器。
- 未实现个人微信外挂、班级协作后台、自动代操作、站外推送或邮箱找回密码。
- 扫描版 PDF 需转页面图片或补充 OCR 文本；旧 DOC/XLS 需另存 DOCX/XLSX。
- 课表只给课节、不含时间时留空要求用户补充；单双周由 AI 展开或标记核对，不猜测钟表时间。
- 所有智能结果为候选建议，确认后进入正式待办。相关主题检测不代表已解决通知版本冲突。

## 配置与运维

保留 Sites/Vinext 和 pnpm 流程。数据模型为 `db/schema.ts`，Drizzle 迁移随版本发布；原始迁移不修改。D1 为 DB，文件桶为 BUCKET。部署前设置密钥 `CAMPUS_ENCRYPTION_KEY`（64 位小写十六进制），不得随意轮换，否则既有用户模型密钥将无法解密。生产密钥与本地开发密钥分别生成。

客户端不接收保存后的服务商密钥。修改接口地址必须同时填写新密钥；请求不跟随重定向，拒绝显式内网/IP地址。站点依赖 Sites 分发层提供可信 ChatGPT 身份头，不能将此头鉴权路径未经适配放到普通公网服务器。

AI 按相关消息组分批处理；大量内容可能耗时，界面保留输入并显示状态。重复批次按原文和来源生成稳定 ID，重试不重复写入同一组原文。
